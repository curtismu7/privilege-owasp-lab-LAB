# privilege-owasp-lab

Tester-tier standalone app: the OWASP Agentic AI Top 10 (ASI01–ASI10) with PingOne Privilege coverage, from the AI-DEMO2 /privilege-owasp-top10 page (read-only source, never imported). Scaffold copied from pingcli-LAB; its CLI-runner features were removed and dataset serving took their place.

- Run: `./scripts/run.sh` (http://localhost:7811). Test: `npm test` (server = `node --test test/*.test.js`, a glob). Preflight: `npm run doctor`. Reset: `npm run reset`. Talk track: `npm run talk-track` (a test fails on drift). Content pack: `npm run content-pack`.
- Core: `commands.js` (the 13-dataset allow-list, prototype-free; labels never carry a caller value), `mockOutput.js` (the static deck wording per vertical: the slide-21 coverage table, category forms, two-layers, placeholder live evidence; fake UUIDs, `.example` hosts), `realRunner.js` (Real: one fixed, read-only management-API invocation; spawn with `shell: false` in its own process group, private 0700 dir + 0600 config + owner.pid, minimal child env, line-buffered scrubber for secret + client id, 15 s timeout, byte cap, session generation so nothing spawns after abort or mode switch, `dispose()` kills and awaits children, `sweepStale` at start-up), `config.js` (four PINGONE_* settings, region -> rootDomain), `readable.js` (pure, shared with the web page: `buildReadableView` understands our `data.rows` and `data.fields` shapes plus the 8000-char JSON highlight cap), `storyData.js` (story, banner, facts with status, the eight scenarios, `{{cast}}` tokens), `trace.js` (hops with the `powasp-*` kinds).
- Rules that bite: no caller-supplied path, query or filter ever reaches the runner (a caller sends only a dataset key); the client secret is write-only; agents never run Real against a tenant; Mock starts no child and makes zero outbound calls; `POST /api/mode` is exactly `{ source }`; one port, 7811; cross-site GETs that spawn are 403; tests give each server its own temp root (`withServer` third arg); only `.example`/`.invalid` hosts; never raise `JSON_HIGHLIGHT_MAX_CHARS` without a measurement.
- Honesty: the coverage wording is the deck's (source: Privilege Capability Overview p.21); explanations are our summaries, labelled UNVERIFIED as "not an OWASP rating"; the gaps (ASI04, ASI06) are stated, never hidden; facts are `observed-in-AI-DEMO2`, `UNVERIFIED` or `lab`. Do not upgrade one without a real run.
- Web: `web/src/App.jsx` (shell bar, banner first, ModeToggle, ThemeToggle, presenter, Reset, five tabs), `components/CoveragePage.jsx` (slide-21 table + category cards with gap chips; output only via `visible()`, never `dangerouslySetInnerHTML`), `CoverageShared.jsx` (collapsible sections, SSE parser), `StoryTab`, `DiagramTab` + generic `PatternDiagram`, `TraceTab` on the vendored `evidence/` screens. Vendored, do not edit: `web/src/evidence/`, `server/src/vendor/`, `scripts/lib/`, `web/src/standalone-ui.css` (pinned by `scripts/check-ui-standard.sh`). Browser check: `npm run e2e` against a running lab.
